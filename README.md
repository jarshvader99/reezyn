# Reezyn

Reezyn is a calm, local narrator for the reasoning behind coding-agent tool
calls. It sits in the macOS menu bar, listens to Claude Code, Codex CLI, Gemini
CLI, and generic agent events, and speaks short excerpts of the agent's own
thoughts through an open-source Kokoro voice.

Everything stays on your machine: transcripts are read locally, speech is
synthesized locally, and no agent content is sent anywhere.

## Status

Early build. The macOS menu-bar app, local Kokoro speech, agent hooks, and
Codex rollout tailing are implemented. See the sections below for setup.
